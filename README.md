## Featured Projects

- **[go-acis](https://github.com/bortiz-101/go-acis)**
  A re-write of xmacis in Go-Lang.

- **[socialspecs](https://github.com/LUC-AI4FM/socialspecs)**
  This project designs and tests TLA⁺ models of social media platforms' written moderation rules. TLC checks each model for paths the rules allow but should not.

- **[FormaLLM](https://github.com/bortiz-101/FormaLLM.git)**  
  This project explores the use of Large Language Models (LLMs) to automatically generate formal specifications in [TLA+](https://lamport.azurewebsites.net/tla/tla.html) from natural language descriptions (comments). The generated specifications are syntactically validated using the TLA+ SANY parser and optionally executed with TLC.
